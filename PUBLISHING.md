# Contributing

## Reporting issues

Open an issue at [github.com/Agentled/mcp-server/issues](https://github.com/Agentled/mcp-server/issues).

## Publishing (maintainers only)

This package is published to npm as `@agentled/mcp-server` by the Agentled team.

```bash
npm publish --access public
```

Requires npm 2FA. Version bumps follow semver:
- `patch` — bug fixes, doc updates
- `minor` — new tools or capabilities
- `major` — breaking changes
