# AgentLed Content LinkedIn

Use this independent bundle to review a LinkedIn draft for clarity, evidence, and audience fit. Read [references/editorial-review.md](references/editorial-review.md) before returning an approval-ready draft.

This bundle does not connect an account, schedule, publish, submit feedback, or trigger generation or spend. When a required source, tool, or capability is unavailable, begin the response with the stable visible label `Partial result:` and state the evidence gap.
